# 妖怪DB（yokai-db）

合同会社妖怪屋が youkai-collection で収集・査読した妖怪データを、どのプロジェクトからでも取り出すためのスキル。
読み取り専用。書き込み（research 登録・昇格）はこのスキルの対象外。

## データソース

| `--source` | 中身 | 認証 |
|---|---|---|
| `academic`（既定） | **学術モードの全国伝承妖怪**（`GET /academic/youkai`）。学芸員が承認した `youkai_core` の公開データ。創作妖怪は除外済み。カテゴリ・伝承地・出典・信頼性スコア付き | Cognito の **premium** アカウント |
| `game` | ゲーム（妖怪コレクション）に配置されている妖怪（`GET /youkai`）。会津・川越などの創作妖怪を含み、画像URL・キーワード付き | 不要 |

基本は `academic` を使う。画像が欲しい時、ゲームに出てくる妖怪を知りたい時、創作妖怪を含めたい時は `--source game`。
学術データが認証エラーで取れない時も `game` で代替できるが、**その場合はデータの性質が違う（創作妖怪を含む・出典なし）ことをユーザーに必ず伝える**。

## 準備：ログイン（academic を初めて使う時）

`academic` は premium アカウントのトークンが要る。トークンが無いとスクリプトが終了コード 2 と `[認証エラー]` を返す。
その時は、パスワードをチャットに書かせず、ユーザー自身にターミナルで次を実行してもらう:

```bash
python3 <このスキルのパス>/scripts/yokai_db.py login
```

メールとパスワードを聞かれ、成功すると `~/.config/yokai-db/token.json`（権限600）に保存される。パスワードは保存されず、リフレッシュトークンで30日間は再ログイン不要。
非対話環境（CI 等）では環境変数 `YOKAI_DB_EMAIL` / `YOKAI_DB_PASSWORD` を設定すれば自動ログインする。

## 基本コマンド

`$S` はこのスキルの `scripts/yokai_db.py` の絶対パス。標準ライブラリだけで動くので、どのプロジェクトでも `python3` があれば使える。
全件を一度取得して `~/.cache/yokai-db/<source>.json` に24時間キャッシュし、検索はローカルで行う（API に検索機能が無いため）。

```bash
python3 $S search -q 河童                       # フリーワード（名前・かな・カテゴリ・伝承地・解説・原文を横断、空白区切りでAND）
python3 $S search --category 天狗               # カテゴリで絞り込み（学術モード画面と同じ正規化済みカテゴリ）
python3 $S search --region 遠野                 # 伝承地名で絞り込み
python3 $S search --near 37.49,139.93 --radius 50   # 座標から半径km以内（近い順・距離付き）
python3 $S get 亀姫                             # 1件の詳細（名前でもIDでも可、md で出典まで表示）
python3 $S info                                 # 件数・取得日時・カテゴリ内訳
python3 $S list                                 # 全件
python3 $S export --format csv --out ./data/yokai.csv   # ファイル出力（json/csv/md、絞り込みオプション併用可）
python3 $S sync                                 # キャッシュ強制更新
python3 $S --source game search -q 会津         # ゲーム用データを検索
```

オプション:
- `--format table|json|csv|md` — 既定は table（get は md）。後続処理なら `json`、文章に貼るなら `md`。
- `--full` — json に全フィールド（出典・スコア・原文）を含める。既定は軽量フィールド。
- `--limit N` — search の既定は 30。`--limit 0` で全件。
- `--refresh` / `--source` はサブコマンドの**前**に置く（例: `python3 $S --refresh search -q 鬼`）。「最新」「さっき昇格した」と言われたら `--refresh`。
- 件数は標準エラーに `# academic: ヒット N 件 …` と出る。

## 検索のコツ

- **まず `info` でカテゴリ内訳を見る**と、どんな切り口で絞れるか分かる。カテゴリは notes 先頭の `[カテゴリ]` 表記を学術モード画面と同じルールで正規化したもの（例: `妖獣・河童説`→`河童`）。元表記は `category_raw`。
- **都道府県・地域での検索は `--region` と `--near` を併用する。** 伝承地は「福島県猪苗代町」のように入っていることもあれば、市町村名や山・寺社名だけのこともある。「福島の妖怪」なら `--region 福島` に加え、`--region 会津` や県の中心座標で `--near … --radius 80` も試し、ID で重複を除いて合わせる。座標は自分の知識で概算してよい（会津若松 37.49,139.93 / 遠野 39.33,141.53 / 東京駅 35.68,139.77）。
- **漢字とかなの両方で引く。** カタカナ⇔ひらがな・全角⇔半角は自動で吸収するが、漢字⇔かなは吸収しない（「河童」と「かっぱ」は別検索）。
- 同名・類名が複数ヒットすることがある（地域違いの河童など）。`get` で候補が複数出たら、伝承地で区別してユーザーに示す。

## 結果の伝え方

- **DB の記載と一般知識を区別する。** 妖怪屋が収集・査読したデータを使えることがこのスキルの価値なので、DB にないことを補う時は「一般的には」「DB には記載なし」と分けて書く。
- 学術データには `sources`（出典URL）と `reliability_score`（AI 信頼性 0–1）がある。紹介文・企画書・論考に使う時は出典を添え、スコアが低い（目安 0.5 未満）ものは「要確認」と注記する。
- 一覧で答える時は「名前 — カテゴリ — 伝承地 — 一言」程度に絞り、詳細は求められたら `get` で出す。
- 見つからない時は、表記を変えて（漢字/かな、略称、上位カテゴリ、`--source game`）再検索してから「DB 未登録」と伝える。未登録はそのまま収集候補なので、そう一言添えると妖怪屋の業務に役立つ。

## 別プロジェクトへの持ち込み

作業中のプロジェクトで使うなら `export` でプロジェクト内に書き出す:

```bash
python3 $S export --format json --out ./data/yokai.json                       # 全件
python3 $S export --format csv  --out ./data/tengu.csv --category 天狗
python3 $S export --format md   --out ./docs/aizu_yokai.md --near 37.49,139.93 --radius 60
```

JSON は `{source, endpoint, fetched_at, count, items:[...]}` 形式で、取得日時が残る。
**学術データは premium 会員向けの有料コンテンツ**なので、公開リポジトリや公開サイトにそのまま置く用途なら、ユーザーに一度確認してから書き出す。
コードから API を直接叩く場合のエンドポイント・認証手順・フィールド定義は `references/data-model.md` を読む。

## エラー時

- 終了コード 2 `[認証エラー]` … 上の「準備：ログイン」へ。`premium グループではない` と出たら、そのアカウントに premium 権限を付ける必要がある（Cognito のユーザープールで `premium` グループに追加）。
- ネットワーク不通・認証切れでも古いキャッシュがあればそれで続行する（警告が出る）。その場合は取得日時をユーザーに伝える。
- プロキシで弾かれる環境では `5rmuhg7c8d.execute-api.ap-northeast-1.amazonaws.com` と `cognito-idp.ap-northeast-1.amazonaws.com` への通信許可が必要。
- 環境変数: `YOKAI_DB_SOURCE`（既定ソース）、`YOKAI_DB_CACHE_DIR`、`YOKAI_DB_CONFIG_DIR`、`YOKAI_DB_TTL`（秒）、`YOKAI_API_BASE`。
